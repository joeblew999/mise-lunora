Why the steps run in this order (found by running both apps from a clean checkout):

1. install: everything needs `node_modules`.
2. generate: vite-react's build fails without `lunora/_generated`.
3. build: TanStack Start writes `routeTree.gen.ts` during build, so type-checking before it fails.
4. verify: passes even with no generated code, so it proves nothing on its own; run it last.

Both apps pass `mise run apps:verify`.
