# 2026-10-27-01-checks.md

Why the steps run in this order, for the apps in `examples/` (both from Lunora's `templates/`):

1. install: everything needs `node_modules`.
2. generate: both builds already run codegen themselves (tanstack-start-react's build script starts with
   `lunora codegen`; the rspack template's Lunora plugin runs it before every compile), so build does not
   need this step first. It was needed only for the removed vite-react app.
3. build: TanStack writes `routeTree.gen.ts` during build, so type-checking before it fails.
4. verify: passes even with no generated code, so it proves nothing on its own; run it last.

Both apps pass `mise run apps:verify`.
