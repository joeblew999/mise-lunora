# 2026-10-27-01-checks.md

Why the steps run in this order, for the apps in `examples/` (both from Lunora's `templates/`):

1. install: everything needs `node_modules`.
2. build: both builds run codegen themselves (tanstack-start-react's build script starts with
   `lunora codegen`; the rspack template's Lunora plugin runs it before every compile), so there is no
   separate generate step in the chain. `app:generate` stays as a task on its own. Build also writes
   framework files: TanStack writes `routeTree.gen.ts` during build, so type-checking before it fails.
3. verify: passes even with no generated code, so it proves nothing on its own; run it last.

Both apps pass `mise run apps:verify`.
